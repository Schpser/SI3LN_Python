## 📋 Astuces

### 💡 Stratégies de Jeu
- **Restez mobile** : Ne restez jamais immobile
- **Visez les côtés** : Éliminez les ennemis sur les bords d'abord
- **Gérez vos tirs** : Maximum 3 bullets à la fois
- **Anticipez** : Les ennemis descendent quand ils touchent les bords

### 🎯 Système de Score
- **10 points** par ennemi × niveau actuel
- Exemple : Niveau 5 = 50 points par ennemi

### ⚙️ Raccourcis Clavier
- **F11** : Plein écran ON/OFF
- **ESC** : Retour/Pause
- **Flèches ou WASD** : Déplacement
- **ESPACE** : Tir

### 🔐 Gestion de Compte
- **Pseudo** : Minimum 3 caractères, unique
- **Mot de passe** : Minimum 4 caractères, hashé (sécurisé)
- **Email** : Optionnel (pour récupération future)
- **Mode invité** : Pas de sauvegarde mais gameplay complet

### 💾 Sauvegardes
- **Comptes** : `data/users.json`
- **Scores** : `data/scores.json`
- Format JSON, facile à éditer/backup

## 🐛 Dépannage

### Le jeu ne démarre pas
```bash
# Vérifier l'installation
python3 test_modules.py

# Vérifier pygame
python3 -c "import pygame; print(pygame.__version__)"
```

### Problème d'affichage
- Essayez F11 pour passer en plein écran
- Redimensionnez la fenêtre manuellement
- Vérifiez votre résolution d'écran

### Scores non sauvegardés
- Vérifiez que vous n'êtes pas en mode invité
- Créez un compte pour sauvegarder

### Performances faibles
- Fermez les autres applications
- Réduisez la taille de la fenêtre
- Désactivez le plein écran
