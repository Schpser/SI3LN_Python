📂 DOSSIER data/ (GÉNÉRÉ AUTOMATIQUEMENT)
═══════════════════════════════════════════════════════════════════════

users.json              Comptes utilisateurs (hashés)
scores.json             Top 20 des meilleurs scores

Format de users.json:
{
  "username": {
    "password": "sha256_hash",
    "email": "user@example.com",
    "selected_character": 0,
    "high_score": 0
  }
}

Format de scores.json:
[
  {
    "username": "player1",
    "score": 5000,
    "level": 10,
    "date": "2025-10-19 14:30:00"
  }
]

COMMANDES UTILES
═══════════════════════════════════════════════════════════════════════

Lancer le jeu:
  python3 main.py
  ou
  python3 launch.py

Tester les modules:
  python3 test_modules.py

Vérifier les assets:
  python3 check_assets.py

Voir la structure:
  tree -L 2

Compter les lignes de code:
  find . -name "*.py" | xargs wc -l
